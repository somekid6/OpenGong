Target setup

The aim point is where the target reports (0, 0): the sensor ring centre unless you moved it with set aim. The jig's rectangular adapter centres the ring on a 12 × 12 in plate by default; if your ring sits off centre, enter the offset here. Settings and shots are kept in this browser, not on the receiver.

Changes are live on the target as soon as they're sent, but are lost when it restarts unless you save them. Plate thickness is used for live fire; calibration taps through the jig ignore it. Commands go over LoRa through the receiver, so each one takes a second or two.

Signal range test

Checks the radio link before live fire. Set both boards in their final positions first. The target fires synthetic shots at P0 and sends them over LoRa like real hits; the receiver measures how strongly each one arrives. Signal range test shots stay in the table but aren't plotted or counted in the group.

The target simulates these shots itself. Don't fire real shots for this test. Keep the plate clear.
